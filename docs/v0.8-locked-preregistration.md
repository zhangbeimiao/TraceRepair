## Protocol

- Run oracle preflight before provider access: buggy target must exit `1`, and
  fixed target plus fixed regression must pass.
- Run each locked task exactly once.
- Publish all successes, handoffs, malformed outputs, test failures, logs, and
  candidate Diff artifacts.
- Do not modify `0.8.0` after observing a locked outcome.
- Do not retry a failed task under the same benchmark ID or Agent version.
- Accept zero patch unless both target and regression tests pass; successful
  candidates still stop at `awaiting_review`.

The result will be reported as a small three-repository pass@1 measurement. It
must not be described as universal code-repair accuracy.
