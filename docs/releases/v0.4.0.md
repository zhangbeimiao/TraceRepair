# TraceRepair v0.4.0

TraceRepair v0.4.0 is the first public, interview-ready release of the bounded code-repair agent.

## Highlights

- Model-driven search, source reading, and candidate patch generation.
- Deterministic path, patch-size, target-test, and regression-test gates.
- SQLite traces and checkpoints for auditability and recovery.
- A dependency-free Web demo built from frozen, sanitized evaluation evidence.
- CI validation on Python 3.11 and 3.12.

## Evaluation snapshot

- Development set: 8/8 successful runs across four bug types.
- Locked one-shot set: 5/5 successful runs across five unseen bug types.
- Combined: 13/13 runs, 224.38 average completion tokens, and 5.0 average tool calls.

These results describe the included EventRelay benchmark only. They are not a claim of a 100% repair rate on arbitrary repositories.

## Try it

- Open the hosted frozen-trace demo: <https://zhangbeimiao.github.io/TraceRepair/>
- Follow the local setup in the repository README to replay the demo or run a live Bailian-backed repair.

No API key, SQLite database, local workspace, or unredacted model response is included in this release.
