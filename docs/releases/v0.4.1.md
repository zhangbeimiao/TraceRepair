# TraceRepair v0.4.1

TraceRepair v0.4.1 improves the public evidence viewer without changing the frozen
`0.4.0-dev1` agent or rerunning the locked evaluation.

## Added

- A verified unified Diff for every successful frozen run. The exporter reconstructs
  the faulty snapshot, compares it with the disposable repaired workspace, and checks
  the repaired content against the SHA-256 stored in the `apply_patch` trace.
- A four-stage verification summary covering patch policy, patch application, target
  tests, and full regression tests.
- Three frozen real-world failure paths: patch context mismatch, diagnosis budget
  exhaustion, and invalid patch output. Each view shows the safe-stop reason and
  whether a patch or test execution was allowed to begin.

## Safety

The browser receives no API key, absolute local path, raw model response, source-tree
dump, or full subprocess log. The site remains a zero-dependency offline viewer over
frozen evidence.
