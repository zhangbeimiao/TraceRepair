# TraceRepair v0.6.0

## Outcome

TraceRepair is no longer coupled to EventRelay at the tool boundary. A validated
JSON task can bind the existing planner, patch policy, tests, trace store, and
checkpoint recovery to another trusted small Python repository.

## Added

- `RepositoryTaskSpec` with schema, path, size, file-count, selector, and drive checks;
- disposable repository materialisation that excludes VCS, virtualenv, cache, and build data;
- configurable read and patch source allowlists;
- exact allowlisted target tests, configurable regression selector and Python path;
- checkpoint persistence of runtime boundaries for safe process resume;
- bundled MiniMath repository and `mini-repo.json` example task;
- zero-token cross-repository demo and public Demo explanation;
- cross-repository success and patch-applied crash-recovery tests.

## Safety statement

This release does not claim that the frozen EventRelay model result generalises
to arbitrary repositories. The second repository is an engineering integration
proof driven by deterministic model responses. Real external repositories must
be trusted because pytest still executes their code without a container sandbox.
